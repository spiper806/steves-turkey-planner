STEVE'S TURKEY PLANNER

FREE GITHUB PAGES SETUP
1. Create a free GitHub account at github.com if needed.
2. Create a new PUBLIC repository named turkey-planner.
3. Upload all five files from this folder to the root of that repository: index.html, app.js, manifest.json, sw.js, icon.png.
4. In repository Settings > Pages, under Build and deployment, choose Deploy from a branch, main, /(root), then Save.
5. Once published, open https://YOUR-USERNAME.github.io/turkey-planner/ in Safari on your iPhone.
6. Tap Share > Add to Home Screen > Add.

No paid hosting or custom domain is needed. GitHub Pages requires a public repository on the free plan.
The app stores settings and checklists locally in your browser; clearing site data may reset them.
Calendar downloads produce .ics files; importing and alerts depend on your iPhone calendar settings.

Cooking schedules are planning estimates. Verify safe turkey temperatures with a thermometer.
